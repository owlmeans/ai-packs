# OwlMeans

OwlMeans builds full-stack web applications (a web interface, an API and a background worker) from
a plain-language description, and keeps developing them one user story at a time. This plugin
connects ChatGPT and Codex to your OwlMeans account through the hosted OwlMeans MCP server, and adds a
skill that explains how to work with it.

## What you can do

- Start a project from a description, review its drafted specification and confirm it to generate
  the application in the OwlMeans cloud.
- Plan, implement and follow user stories.
- Check the cloud preview, publish the application to production, attach a custom domain, manage
  the application's users and link a GitHub repository.

## What it connects to and what it sends

- The plugin runs nothing on your computer. It connects to one remote server operated by OwlMeans:
  `https://api.owlmeans.com/mcp/openai`.
- You sign in with your OwlMeans account (OAuth) the first time you use it.
- The server receives what you ask its tools to do: project descriptions, story text, the names and
  settings you choose. It is processed under the OwlMeans privacy policy.
- Generating and developing applications spends credits from your OwlMeans account. Billing, plans
  and credit top-ups stay in the OwlMeans web app.
- Tools whose effect cannot be undone ask for confirmation first.
